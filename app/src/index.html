    DuckDB engine

    Duckbench runs entirely in your browser on @duckdb/duckdb-wasm, fetched from jsDelivr. You can pin an exact version or check for the latest stable release.

    A dataset is loaded in this tab, so switching versions here is disabled — swapping the engine mid-session can silently break the loaded table. Reload the page to start a fresh session on a different version.
